# Full-Stack Clinic App

A complete clinic management system with backend API and frontend dashboard.

## Structure

* **ClinicApi/** → ASP.NET Core backend (C#)
* **clinic-client/** → React frontend

## Features

* Manage Doctors, Patients, and Appointments
* Full CRUD operations
* REST API integration
* Clean UI dashboard

## Tech Stack

* Backend: ASP.NET Core (.NET 8), Entity Framework, SQL Server
* Frontend: React, JavaScript, CSS

## Run Backend

```bash
cd ClinicApi
dotnet run
```

## Run Frontend

```bash
cd clinic-client
npm install
npm start
```

Frontend:
👉 http://localhost:3000

Backend:
👉 http://localhost:5041/swagger
